# LUCK LAB — バーチャル・アーケード (Alpha 0.1)

**完全オフラインの架空チップ・ゲーム**。スロット、欧州式ルーレット、簡易ブラックジャックを30ラウンド遊び、最終チップと勝敗履歴を振り返ります。現実のお金と交換できる資産は一切ありません。

## 操作

- リポジトリの開発用ブランチをZIPで取得し、`index.html` をブラウザーで開いて遊べます。
- Windows用の署名なしSetup/Portable版は [GitHub Actions](https://github.com/shihuiarenjinba-png/game/actions/workflows/windows-build.yml) で開発用に生成します。配布用の署名・実機受け入れ試験は未完です。
- **初期2500C、1プレイ10〜200C・10C刻み**。30ラウンドが終了するか、10C未満になるとゲーム終了。ブラウザーのlocalStorageに自動保存。
- **スロット**：6絵柄の独立した重み付き抽選。最初の2つが同じなら2倍、3つ一致は絵柄により8〜45倍（賭けチップを含む総払戻し）。
- **ルーレット**：欧州式の0〜36、単一番号の合計36倍、赤黒・奇偶は合計2倍。0は赤黒・奇偶では外れ。
- **ブラックジャック**：A=1/11、絵札=10点。ヒット・スタンド・最初の2枚でのダブルを選択。ディーラーは17以上で止まる。標準ルールのナチュラルBJは合計2.5倍、通常勝利2倍、引き分けは掛けチップ返却。ディーラー有利チャレンジは別途明示する独自ルール。教育用に毎手番新しい簡略デッキを使用し、実際のカジノと完全同一のルールではありません。

### ブラックジャックの難易度（Alpha 0.2）

初期設定は**ディーラー有利チャレンジ**です。これは通常のブラックジャックではなく、**特別な架空ルールとして明記したモード**です。

- プレイヤーは21点を超えると失格。
- ディーラーは**23点まで有効**（24点以上で失格）、同点もディーラーの勝ち。ナチュラルBJは通常どおり優先。
- 比較用に通常の**標準ルール**にも切り替え可能。こちらは双方21点超で失格、同点は引き分けでチップ返還。
- 固定の簡単なプレイヤー行動（16点以下で引き、それ以外はスタンド）による3,000シード試算では、ハウス有利モードで2,080回（約69%）をディーラー側が獲得。これは同じ行動方針の結果であり、すべてのプレイヤーの勝率とは異なります。
- **隠れた勝敗操作・勝率の偽装は行いません。** 難しいルールをゲーム開始前に表示し、設定で変更できます。実際のカジノのルール・確率ではありません。
- ディーラーの勝数・勝率は画面で確認できます。

## 会計と乱数

すべての仮想チップ支出・払戻しを台帳へ記帳し、どの状態でも残高と合計が一致するようにします。Seed付き疑似乱数を使用して再現可能なテストを行います。この疑似乱数は**暗号学的・ギャンブル規制用の乱数ではありません**。実際のお金を賭ける用途には絶対に使用しないでください。

`npm test` はNode標準機能でゲーム計算・台帳・ルーレット37番号、スロット・ブラックジャック、セーブ・UIを検査します。Windows Actionsでは実際のElectron画面で3ゲームをプレイし、ブラウザー相当の表示幅・125%ズームをキャプチャします。

## Alpha 0.2.1のUI改善

画面上部の余白を減らし、ディーラーカード・プレイヤーカード・操作ボタンの見やすさを改善しました。30ラウンドの進捗バーを追加し、キーボードでは **H=ヒット、S=スタンド、D=ダブル、スペース=スロット/ルーレット実行** に対応しています。通常のセレクトボックスを操作している際はショートカットが動かないようにしています。これらは自動UI検証に加え、販売前の手動DPI・キーボード操作検証が必要です。
